# /assets

Carpeta para las imágenes del sitio.

Coloca aquí las fotos reales y actualiza las rutas en `index.html`:

- `placeholder-hero.jpg` → foto de retrato para la sección Hero (usada en `index.html`, sección `#inicio`).
- `placeholder-about.jpg` → foto para la sección "Sobre mí" (usada en `index.html`, sección `#sobre`).

Mientras no exista el archivo, el sitio muestra un fondo de color de respaldo
automáticamente (no se rompe el diseño).
